 Copy to your Vim config directory:

 ``` console
$ mkdir -p ~/.vim/syntax ~/.vim/ftdetect
$ cp syntax/picjs.vim ~/.vim/syntax/
$ cp ftdetect/picjs.vim ~/.vim/ftdetect/
```

Or for Neovim:

``` console
$ mkdir -p ~/.config/nvim/syntax ~/.config/nvim/ftdetect
$ cp syntax/picjs.vim ~/.config/nvim/syntax/
$ cp ftdetect/picjs.vim ~/.config/nvim/ftdetect/
```
